# AI-103 Exam Blueprint

Last reviewed: September 14, 2026

## Exam purpose

Exam AI-103, Developing AI Apps and Agents on Azure, is intended for Azure AI engineers who build, manage, and deploy agents and AI solutions with Microsoft Foundry. Candidates should be comfortable developing Python applications and should understand general AI, generative AI, and relevant Azure services.

The role includes planning and managing Azure AI solutions, building generative and agentic applications, implementing computer vision and text analysis, and extracting information from documents and other content.

## Skills measured

The skills measured as of April 16, 2026 are divided into five domains:

- Plan and manage an Azure AI solution: 25–30%
- Implement generative AI and agentic solutions: 30–35%
- Implement computer vision solutions: 10–15%
- Implement text analysis solutions: 10–15%
- Implement information extraction solutions: 10–15%

## Planning and management

Candidates should know how to choose models and Foundry services for generative AI, agents, grounding, vector search, multimodal processing, memory, tools, and knowledge integration. They should be able to design Azure infrastructure, select deployment options, configure model and agent deployments, and integrate projects with CI/CD pipelines.

Operational knowledge includes quotas, scaling, rate limits, cost, monitoring, safety events, grounding quality, ingestion quality, and search relevance. Security topics include managed identity, private networking, keyless credentials, role policies, trace logging, provenance, approval workflows, and tool-access controls.

## Generative AI and agents

Candidates should be able to deploy and consume large, small, code, and multimodal models. Important application patterns include retrieval-augmented generation, prompt engineering, structured outputs, tool-augmented workflows, multistep reasoning, and model evaluation.

Agent skills include defining roles and goals, tracking conversations, designing tool schemas, integrating function calling and retrieval, connecting APIs and knowledge stores, orchestrating multiple agents, adding safeguards, and monitoring agent behavior.

## Vision, text, and information extraction

Vision objectives cover image and video generation, image editing, captions, visual question answering, alt text, object or region identification, visual safety, and prompt-injection risks embedded in images.

Text objectives include extracting entities and topics, summarization, structured JSON, sentiment, tone, safety classification, translation, speech-to-text, text-to-speech, and audio reasoning.

Information extraction focuses on ingesting and indexing documents and media, semantic and hybrid search, vector search, enrichment, OCR, layout analysis, field extraction, and clean grounded representations for agents and RAG systems.

## Study approach

Use the blueprint as a checklist, but practice each domain through working projects. For every project, be able to explain the architecture, identity model, failure modes, evaluation strategy, monitoring, cost considerations, and responsible AI controls.
